# Webcams Auvergne

Carte des webcams entre Clermont-Ferrand et Aurillac (dans un rayon de 100 km autour de l'axe), utilisable sur téléphone et ordinateur.

- `index.html` : la page
- `app.js` : carte, chargement des caméras routières Bison Futé en direct, statut « en direct »
- `webcams.js` : liste des webcams de stations et de villages (à compléter)
- `style.css` : apparence

L'axe et le rayon se règlent en haut de `app.js` (`ZONE_A`, `ZONE_B`, `ZONE_KM`).

Aucune installation : ce sont des fichiers statiques, publiés avec GitHub Pages.
